# 🎈 ছোটদের কথা বলা বই (Kids Interactive Talking Learning App)

আপনার দেওয়া **"English Book Play"** রিসোর্স (PDF) থেকে তৈরি বাচ্চাদের জন্য একটি সম্পূর্ণ ইন্টারেক্টিভ ও কথা বলার লার্নিং ওয়েব অ্যাপ।

---

## 🌟 প্রধান ফিচারসমূহ (Features)

1. **🐻 কথা বলা বন্ধু (Animated Talking Mascot - টিটু):**
   - কথা বলার সময় মুখ ও চোখ নাড়ায় (Lip-sync animation)।
   - বাচ্চাদের উৎসাহ দেওয়া ও মিষ্টি মিষ্টি প্রশংসা করা।
   - যেকোনো শব্দের অর্থ ও উচ্চারণ স্বয়ংক্রিয়ভাবে বুঝিয়ে বলা।

2. **🃏 টকিং ফ্ল্যাশ কার্ডস (Talking Flashcards Mode):**
   - বইয়ের ১৪টি পৃষ্ঠা ও ৯টি ক্যাটাগরির **১০২টি শব্দের আসল রঙিন ছবি ও শব্দার্থ**।
   - **English এ শোনো:** নেটিভ স্পষ্ট উচ্চারণ।
   - **বাংলায় শোনো:** বাংলা অর্থ ও ব্যাখ্যা।
   - **🐢 কচ্ছপ মোড (Slow Pronunciation):** ধীরে ধীরে প্রতিটি শব্দ শোনার সুবিধা।
   - **🔤 বানান মোড (Spell-it-out):** প্রতিটি বর্ণ (Letter by Letter) বানান করে পড়ে শোনানো।
   - **💡 মজার বাক্য (Example Sentence):** ছোটদের উপযোগী সহজ সুন্দর বাক্য।

3. **🎯 শুনে খোঁজো কুইজ (Listen & Find Quiz Game):**
   - টিটু মুখে প্রশ্ন করবে (যেমন: *"Where is Watermelon?"* / *"বলো তো কোনটি সিংহ?"*)।
   - ৪টি রঙিন ছবির মধ্য থেকে বাচ্চারা সঠিক ছবিতে ট্যাপ করবে।
   - সঠিক উত্তরে কনফেটি (Confetti 🎉), মিউজিক্যাল ফ্যানফেয়ার ও স্টার পুরস্কার (⭐)।

4. **🎤 তুমিও বলো - স্পিকিং প্র্যাকটিস (Voice Assessment Game):**
   - বাচ্চারা বড় মাইক বাটনে চাপ দিয়ে ইংরেজিতে উচ্চারণ করবে।
   - স্পিচ রিকগনিশন (Speech Recognition) স্বয়ংক্রিয়ভাবে বাচ্চার উচ্চারণ শুনে যাচাই করবে এবং ফিডব্যাক দেবে।

5. **🧩 জোড়া মেলাও (Memory Match Puzzle):**
   - ছবি ও শব্দের কার্ড উল্টিয়ে একই জোড়া মেলানোর মেমোরি গেম।
   - স্মৃতিশক্তি ও শব্দ শেখার যুগপৎ বিকাশ।

6. **▶️ অটো-প্লে স্টোরিবুক মোড (Autoplay Mode):**
   - ছোট বাচ্চাদের জন্য স্বয়ংক্রিয় স্লাইডশো। বইয়ের মতো একটার পর একটা ছবি আসবে এবং পড়ে শোনাবে।

7. **⭐ স্টার রিওয়ার্ডস ও সাউন্ড সিন্থেসাইজার:**
   - প্রতি সঠিক উত্তরে গোল্ডেন স্টার সংগ্রহ।
   - Web Audio API দিয়ে তৈরি দ্রুত ও মিষ্টি কার্টুন সাউন্ড এফেক্টস।

## 🚀 কীভাবে চালাবেন (How to Run)

### পদ্ধতি ১ (সবচেয়ে সহজ):
শুধু `index.html` ফাইলে ডাবল-ক্লিক করলেই যেকোনো ব্রাউজারে (যেমন Google Chrome, Edge) অ্যাপটি চালু হয়ে যাবে।

### পদ্ধতি ২ (লোকাল সার্ভার চালু করে):
টার্মিনালে লিখুন:
```bash
python server.py
```
এরপর ব্রাউজারে `http://localhost:8000` লিঙ্কে অ্যাপটি ওপেন হবে।
